# AluGames — Aluguel de Boardgames

Página web que simula o controle de aluguel de jogos de tabuleiro: cada jogo mostra se está disponível ou alugado, e um clique alterna entre **Alugar** e **Devolver**. Projeto feito nos estudos de lógica de programação da Alura.

---

## Funcionalidades

- Catálogo com Monopoly, Ticket to Ride e Takenoko
- Botão que aluga ou devolve o jogo, com mudança visual da capa e do botão
- Layout com nomenclatura de classes no padrão BEM

## Como executar

Basta abrir o `index.html` no navegador.

## O que pratiquei

- Funções com parâmetro para reaproveitar a mesma lógica em todos os jogos
- Manipulação do DOM com `getElementById`, `querySelector` e `classList`
- Controle de estado pela presença ou ausência de uma classe CSS

## Tecnologias

`HTML` `CSS` `JavaScript`
